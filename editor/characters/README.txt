캐릭터 팩 폴더
- 캐릭터마다 폴더 하나 (예: jinyang/), 안에 그림 파일(PNG 권장, 배경 투명이면 가장 깔끔. 흰 배경도 자동으로 지움)
- index.json 에 이름과 파일 목록을 적는다:
  [{"id": "jinyang", "name": "지냥이", "images": ["jinyang/1.png", "jinyang/2.png"]}]
- 지금 들어 있는 jinyang/1~3.svg 는 임시 샘플. 실제 지냥이 그림으로 바꾸고 index.json 파일명도 맞출 것
- 바꾼 뒤 Netlify에 editor 폴더 다시 올리기
