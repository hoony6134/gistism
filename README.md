# 서비스러닝 포토부스

터치 디스플레이 + 캐논 EOS RP(HDMI 캡처보드) + 캐논 SELPHY CP1500으로 돌리는 네컷 포토부스.

```
photobooth/
├─ start-booth.bat     ← Windows에서 더블클릭하면 부스 실행
├─ start-booth-mac.command ← Mac에서 내장 카메라로 시험해 볼 때 더블클릭
├─ server.ps1          ← Windows용 로컬 서버 (설치 필요 없음)
├─ server.py           ← Mac/라즈베리파이/개발용 로컬 서버 (같은 기능)
├─ booth/              ← 부스 화면 (config.js에서 설정)
├─ frames/             ← 프레임 이미지 (normal = 일반, character = 캐릭터, _guide = 디자이너용 가이드)
├─ editor/             ← 폰 프레임 에디터 (인터넷에 올려서 사용)
├─ supabase/setup.sql  ← 클라우드 DB 설정
├─ output/             ← 촬영 결과 자동 저장 (날짜별, 원본 6장 + 인쇄본)
└─ logs/               ← 운영 로그 (날짜별 .jsonl — 이용자 수·소요 시간·오류)
```

## 1. 부스 PC 준비 (Windows)

1. **Chrome 설치** (없으면 Edge로 자동 실행됨)
2. **CP1500 드라이버 설치** → 캐논 홈페이지에서 SELPHY CP1500 Windows 드라이버
3. **CP1500을 기본 프린터로 지정**: 부스 실행 후 관리자 메뉴 → **프린터**에서 CP1500을 고르면 된다 (이 PC의 기본 프린터로 정하고, "Windows에서 기본 프린터 관리"도 꺼 줌). Windows 설정에서 직접 해도 같음
4. **CP1500 인쇄 기본 설정**: 프린터 속성 → 인쇄 기본 설정
   - 용지 크기: **엽서 (100×148mm)**
   - 테두리: **테두리 없음**
   - 방향: 세로
5. **카메라 연결**: EOS RP → 마이크로 HDMI 케이블 → 캡처보드 → PC의 **파란색 USB 3.0 포트**
6. **카메라 설정**
   - 동영상 모드, 더미 배터리 + AC 어댑터
   - HDMI 정보 표시 끄기 (화면에 아이콘 없이 깨끗하게)
   - AF: 무비 서보 AF + 얼굴 추적
   - 노출: 조명 세팅 후 수동(M)으로 고정
   - 자동 전원 꺼짐: 해제
7. `photobooth` 폴더를 PC에 통째로 복사 (경로는 어디든 OK)

## 2. 실행

| 실행 방법 | 용도 |
|---|---|
| `start-booth.bat` 더블클릭 | **행사용**. 창으로 열리고 **첫 터치 때 전체화면**으로 바뀜. 인쇄 대화상자 없이 바로 출력 |
| 명령 프롬프트에서 `start-booth.bat setup` | **프린터 세팅용**. 인쇄 대화상자 표시 |

- 종료: `Alt + F4` 로 브라우저 닫기 → 작업 표시줄의 "photobooth-server" 창 닫기
- **왼쪽 위 모서리를 3초 안에 5번 터치** → 관리자 메뉴 (PIN 기본값 `0000`, `booth/config.js`에서 변경)
  - **촬영 설정**: 첫 장 카운트다운, 다음 장 카운트다운, 보너스 컷 수 (− / + 로 바꾸면 이 PC에 저장)
  - **화면**: 전체화면 / 창 모드 / **모니터 고르기** (모니터가 여러 대면 부스를 띄울 화면 선택. 처음 한 번 "창 관리" 권한 허용). 고른 방식은 저장돼서 다음 실행 때 첫 터치에 다시 적용
  - **사진 색감**: 밝기 · 대비 · 채도 · 따뜻하게 (카메라 노출은 카메라에서 맞추고, 여기서는 들어온 화면을 살짝 보정. 미리보기와 찍히는 사진에 똑같이 적용)
  - 카메라 선택·해상도, 좌우 반전, **촬영 소리**(카운트다운 삑 · 셔터 찰칵) 켜기/끄기, 프레임 켜기/끄기, 테스트 인쇄, 오늘 현황
  - **프린터**: 고른 프린터를 이 PC의 기본 프린터로 정한다. 인쇄는 브라우저 인쇄로 기본 프린터에 나간다
  - 카메라 화면 양옆의 진짜 검은 띠(완전한 검정, 양쪽 같은 너비)는 자동으로 잘라내고 너비에 맞춘다. 카메라 칸의 체크로 끌 수 있다

**첫 세팅 순서**: `setup`으로 실행 → 관리자 메뉴에서 카메라·모니터 선택 → 테스트 인쇄 1장 → 여백·잘림 확인 → 창 닫고 행사용으로 실행

### 촬영 흐름
- 홈 화면: 카메라에 비친 모습 위에 **일반 네컷 / 캐릭터 네컷** 카드 (프레임이 없는 종류는 숨겨짐)
- **일반**: 촬영 준비 → 찍기 → **사진 4장 고르기** → 고른 사진이 들어간 프레임 중에서 고르기 → 출력 매수 → 인쇄
- **캐릭터**: 프레임 고르기 → 촬영 준비 → 지금 찍는 칸에 실시간 카메라가 들어간 프레임 화면을 보면서 찍기 → 사진 확인 → 출력 매수 → 인쇄
- **촬영 준비** 화면: 미리보기로 자리 잡기 + 몇 컷·몇 초·몇 장 고르는지 안내. "촬영 시작"을 누르거나 15초가 지나면 시작
  - 찍는 장수 = 켜진 일반 프레임 중 가장 많은 칸 수(보통 4) + 보너스 컷

## 3. 프레임 만들기 · 추가하기

### 어디에 넣나
**이미지 파일(JPG·PNG)을 폴더에 넣기만 하면 된다.** 좌표 입력 필요 없음.

```
photobooth/frames/
├─ normal/        ← 일반 프레임 (먼저 찍고 고르는 프레임)
│   ├─ 01_지냥이네컷.jpg
│   └─ 02_교수네컷.jpg
├─ character/     ← 캐릭터 프레임 (프레임 보면서 찍는 프레임)
│   └─ 01_캐릭터-예시.jpg
├─ _guide/        ← 디자이너용 가이드 (부스에는 안 나옴)
└─ _examples/     ← 예전 방식(frame.json) 샘플 (부스에는 안 나옴)
```

- 화면에 보이는 이름 = 파일 이름. 앞의 숫자와 `_`는 순서용이라 이름에서 빠진다 (`01_지냥이네컷.jpg` → "지냥이네컷", 01번째)
- 넣은 뒤 관리자 메뉴 → "프로그램 새로고침" (또는 프로그램 재실행)
- 잠깐 안 쓸 프레임은 지우지 말고 관리자 메뉴에서 끄기. 칸을 못 찾은 파일은 관리자 메뉴 "프레임 켜기/끄기" 아래에 빨간 글씨로 나온다

### 어떻게 만드나

| 종류 | 이미지 크기 | 인쇄 결과 | 가이드 파일 |
|---|---|---|---|
| **스트립** | **600 × 1800 px** (1:3) | 4×6 용지 한 장에 **같은 줄 2개**가 나란히 → 잘라서 2명이 나눔 | `_guide/strip-guide-600x1800.svg` |
| 한 장 (2×2 등) | **1200 × 1800 px** (2:3) | 4×6인치 한 장 전체 | `_guide/2x2-guide-1200x1800.svg` |

- **사진 칸 = 마젠타 #FF00FF로 꽉 칠하기 (JPG)** 또는 **투명하게 뚫기 (PNG)**. 부스가 그 부분을 찾아서 사진을 넣는다
  - 마젠타는 사진 칸에만. 캐릭터·글자·배경에 진분홍(#FF00FF와 비슷한 색)을 쓰면 그 부분도 칸으로 잡힐 수 있다
  - 칸 개수·위치·크기는 자유. 칸은 위→아래, 왼쪽→오른쪽 순서로 1, 2, 3, 4번이 된다
- **캐릭터가 칸 위에 걸쳐도 된다**: 칸 색이 아닌 부분(캐릭터·글자)은 사진 위에 그대로 인쇄된다. 단 캐릭터가 칸을 완전히 두 동강 내면 칸이 둘로 잡히니 주의
- 크기가 조금 달라도 비율(1:3 또는 2:3)이 맞으면 자동으로 맞춘다. 가로가 더 긴 이미지는 못 쓴다
- **빨간 점선(안전 영역) 안쪽에 글자·로고**: 바깥쪽 20~40px은 인쇄할 때 살짝 잘릴 수 있다
- 카메라 화면이 가로라서 세로로 긴 칸일수록 양옆이 많이 잘린다 (스트립은 가로 3:2 칸 추천)

**디자이너(피그마·캔바)에게 전달할 것**: 가이드 SVG를 불러와서 그 위에 디자인 → 분홍 칸은 그대로 두고 JPG(또는 칸을 지운 PNG)로 내보내기 → `normal` 또는 `character` 폴더에 넣기.

### 예전 방식 (frame.json)
`frames/<폴더>/frame.json` + 오버레이 이미지 방식도 그대로 된다 (`_examples` 참고. 폴더를 `frames/` 바로 아래로 옮기면 켜짐). `"type": "character"`를 넣으면 캐릭터 프레임.

## 4. 폰으로 나만의 프레임 (선택 기능, 지금은 꺼 둠: `booth/config.js`의 `customFrames: true`로 켬)

인터넷이 필요하다. 설정하지 않으면 이 기능만 꺼지고 나머지는 오프라인으로 잘 동작한다.

### 4-1. Supabase 만들기 (무료)
1. https://supabase.com 가입 → New project
2. 왼쪽 **SQL Editor** → `supabase/setup.sql` 내용 붙여넣기 → Run
3. **Project Settings → API**에서 두 값을 복사
   - Project URL (예: `https://abcd1234.supabase.co`)
   - anon / publishable 키

### 4-2. 에디터를 인터넷에 올리기
1. `editor/config.js`에 Supabase URL과 키 입력
2. **지금은 Vercel**: GitHub 저장소 `hoony6134/gistism`을 Vercel에서 가져오기 → 주소 `https://gistism.scian.xyz/` (기본 주소 `https://gistism.vercel.app/`)
   - Root Directory `editor`, Framework Preset `Other`, Build Command 비움, Output Directory `.`
   - `main`에 푸시하면 자동으로 다시 배포된다
   - 예전 Netlify(`srpphotobuth.netlify.app`)나 다른 정적 호스팅도 그대로 쓸 수 있다

### 4-3. 부스에 연결
`booth/config.js`에 입력:
```js
supabaseUrl: 'https://abcd1234.supabase.co',
supabaseAnonKey: '...',
editorUrl: 'https://gistism.scian.xyz/',   // 사진 받기 QR = 이 주소 + photo.html
```
→ 대기 화면에 에디터 QR, 프레임 선택 화면에 "내 프레임" 버튼, 완료 화면에 사진 다운로드 QR이 생긴다.

### 사용 흐름
폰으로 QR → 템플릿 선택 → 스티커·사진·글자 꾸미기 → 완성 → **4자리 번호** → 부스에서 "내 프레임" → 번호 입력 → 미리보기 확인 → 촬영

- 번호는 48시간 동안 유효
- 스티커·사진·글자는 사진 칸 위에도 올릴 수 있다 (촬영 사진 위에 그대로 얹혀서 인쇄됨). 선택한 요소의 왼쪽 위 ✕로 삭제
- 부스의 미리보기 화면에서 운영자가 부적절한 프레임이면 "다른 번호 입력"으로 돌려보내면 된다
- **행사 후 정리**: Supabase → Storage에서 `frames`, `photos` 버킷 비우기 → SQL Editor에서 `delete from public.custom_frames;`

### 4-4. 캐릭터 프레임 만들기 (자동 배치, 추천)
콜라보 네컷처럼 작은 캐릭터 그림을 사진 칸 주변에 배치한 프레임을 만든다. AI·인터넷 계정 필요 없음.

1. 폰 에디터에서 **"콜라보" 템플릿**(그레이·크림·화이트·핑크 스트립) 선택
2. 아래 **🐶 캐릭터** → "캐릭터 그림 올리기 (여러 장)" → 최대 10장
   - 흰/단색 배경은 자동으로 지움 (배경이 투명한 PNG가 가장 깔끔)
   - 사진 칸 모서리·가장자리(걸터앉기, 빼꼼, 매달리기)에 자동 배치. 칸 가운데(얼굴 자리)는 가리지 않음
   - "🔀 다시 배치"로 섞기, 손으로 옮기기·크기 조절·✕ 삭제 가능
3. 다른 템플릿(2×2 포함)에서도 캐릭터 버튼을 쓸 수 있다
4. **🎨 배경 → 사진 칸 모양**: 사각 / 둥근 / ☁️ 구름(물결). 칸 모양대로 프레임에 구멍이 뚫리고 부스 사진이 그 모양으로 보인다
5. **Aa 글자 → 💬 말풍선으로 넣기**: "안아줘!" 같은 말풍선을 캐릭터 옆에 놓기

### 4-5. AI로 캐릭터 프레임 만들기 (지금은 꺼 둠: `editor/config.js`의 `aiEnabled: true`로 켬)
폰 에디터 첫 화면 "✨ AI로 캐릭터 프레임 만들기":
1. **캐릭터 이름** 입력 (예: 가나디, 피카츄) — 검색하면 나오는 유명 캐릭터만 대상. 사진 첨부 없음
2. **분위기** 버튼(귀엽게·파스텔·벚꽃·우주…) + 직접 입력
3. **Gemini / ChatGPT / Copilot** 중 하나 누르기 → 요청문이 복사되고 그 앱이 열림 → 붙여넣고 보내기 (안 그려 주면 다른 AI로)
4. 그림 저장 → **만든 그림 올리기** → 사진 칸(가이드 위치)이 자동으로 뚫리고 편집 화면으로
- 요청문은 `editor/ai-prompt.js`. 사진 칸은 마젠타(#FF00FF)로 칠하게 하고, 에디터가 가이드 칸 안의 칸 색만 투명하게 만든다 → 칸에 걸친 캐릭터는 사진 위에 남음
- 무료로 나눠주는 건 괜찮지만, 유명 캐릭터 프레임으로 **돈을 받으면 저작권 문제**가 될 수 있음

(선택, 유료) 앱 안에서 바로 생성: `editor/config.js`의 `aiAutoEnabled: true` + Supabase 서버 함수(`supabase/functions/generate-frame`) + `GEMINI_API_KEY`(결제 필요, 장당 약 46원). 설정 방법은 노션 "캐릭터 프레임 만들기" 페이지.

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "카메라를 찾지 못했어요" / 테스트 화면이 나옴 | 캡처보드 USB 다시 꽂기 → 관리자 메뉴에서 카메라 선택 → 새로고침. 다른 프로그램(OBS, 카메라 앱)이 캡처보드를 쓰고 있으면 끄기 |
| 화면이 검은색 | 카메라 전원, HDMI 케이블, 카메라가 동영상 모드인지 |
| 화면에 카메라 아이콘·초점 표시가 보임 | 카메라 메뉴에서 HDMI 정보 표시 끄기 |
| 인쇄가 안 나옴 | CP1500이 기본 프린터인지, 용지·잉크 카세트. 놓친 사진은 `output/날짜/…_sheet.jpg`를 열어서 다시 인쇄 |
| 인쇄물에 흰 테두리 / 잘림 | 프린터 기본 설정의 용지 크기·테두리 없음 확인. 필요하면 `booth/config.js`의 `paperWidthMm/HeightMm` 조정 |
| 프로그램 멈춤 | `Alt+F4` → `start-booth.bat` 다시 실행. 촬영 결과는 이미 `output/`에 저장돼 있음 |
| "프레임 목록을 불러오지 못했어요" | photobooth-server 창이 켜져 있는지. 꺼졌으면 `start-booth.bat` 다시 실행 |
| 내 프레임 번호를 못 찾음 | 인터넷 연결, 48시간이 지났는지, 번호 오타 |
| 넣은 프레임이 안 보임 | `frames/normal` 또는 `frames/character`에 넣었는지, 관리자 메뉴 → 프로그램 새로고침. 관리자 메뉴 빨간 글씨(칸을 못 찾음 등) 확인 |
| 사진 칸이 이상하게 잡힘 | 칸을 #FF00FF로 꽉 칠했는지, 다른 곳에 비슷한 진분홍을 쓰지 않았는지 |
| 전체화면이 안 됨 / 다른 모니터에 뜸 | 화면을 한 번 터치(첫 터치에 전체화면). 관리자 메뉴 → 화면 → 모니터 고르기 |

## 6. 운영 데이터 (2차 운영 개선용)

`logs/YYYY-MM-DD.jsonl`에 한 줄씩 기록된다.

- `session_start` 시작 / `mode_selected` 일반·캐릭터 / `frame_selected` 고른 프레임 / `shoot_done` 촬영 시간
- `print` 인쇄(장수, 시작부터 인쇄까지 걸린 초) / `session_abandoned` 중간 이탈(어느 화면에서)
- `error` 오류(어디서, 메시지)

엑셀에서 열거나 개발 담당에게 요청하면 이용자 수, 프레임별 인기, 평균 소요 시간, 이탈 지점, 오류 횟수를 바로 뽑을 수 있다.

## 7. Mac에서 시험해 보기 (맥북 내장 카메라)

1. `start-booth-mac.command` 더블클릭
   - 처음 한 번 "확인되지 않은 개발자" 경고가 뜨면: 파일을 **우클릭 → 열기 → 열기**
   - 처음 한 번 macOS가 Chrome의 카메라 사용을 물어보면 허용
2. Chrome 창에 부스 화면이 뜬다 (전체화면·창 모드는 관리자 메뉴 → 화면)
3. 다 쓰면 Chrome 창을 닫으면 서버도 같이 꺼진다

- 내장 카메라(FaceTime)로 촬영 → 고르기 → 인쇄까지 그대로 동작한다
- 인쇄 버튼을 누르면 Chrome 인쇄 창이 뜬다 → "PDF로 저장"으로 결과물 확인, 또는 취소 (결과는 `output/`에 이미 저장됨). Mac에 CP1500을 연결했다면 실제 인쇄도 된다
- 외장 카메라·캡처보드를 꽂았으면 관리자 메뉴 → 카메라에서 선택
- 수동 실행: 터미널에서 `python3 server.py` → http://localhost:8787/booth/ (에디터는 /editor/)
